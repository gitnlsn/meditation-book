# Translation contract — *The Trainable Mind*

The English edition of *A mente treinável*, titled ***The Trainable Mind:
Buddhism, Meditation and the Brain That Changes***, in
`books/the-trainable-mind/`. The general rules are in `docs/translation-en.md`;
this file holds what is particular to this book, and wins over the general
file when they disagree.

## Voice

The same as the Portuguese: clear, direct, explanatory, *you* where the
Portuguese uses *você*. See `CLAUDE.md`. It should read as if written in
English: idiomatic US English, plain words, no calques ("it is worth noting
that", "in this sense" only where natural). Short sentences stay short.

## Quotations

- **Suttas:** the Portuguese translated Bhikkhu Sujato's English. The English
  edition **quotes Sujato directly** from `sources/sujato-<id>-en.md` (CC0),
  exactly as printed there, and the foot note becomes: *Sutta passages are
  quoted from Bhikkhu Sujato's translations (SuttaCentral, public domain).*
  Adapt it if the chapter used another translation (Mendis, Ñāṇamoli,
  Thanissaro), naming it.
- Where the Portuguese paraphrased a sutta ("em tradução livre"), the English
  may quote Sujato's wording instead if it covers the same passage; otherwise
  paraphrase closely.
- **Any other English original** (a paper's sentence, Kabat-Zinn's definition,
  Barry Gordon in *Scientific American*) is quoted from the original as
  recorded in `sources/VERIFIED.md` or the file in `sources/`, never
  back-translated. If the original wording isn't recorded, paraphrase without
  quotation marks.
